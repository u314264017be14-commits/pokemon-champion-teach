# 換人與擊掌奇襲

- 換人在所有招式之前完成，攻擊由新上場的寶可夢承受
- 擊掌奇襲：優先度 +3，讓目標畏縮，只限上場第一回合
- 熾焰咆哮虎：擊掌奇襲、拋下狠話換下，再上場重發威嚇

## 圖解
類型：流程圖
最終狀態：中央標示熾焰咆哮虎，四格排成一圈，箭頭依序連接，最後一格的箭頭回到「擊掌奇襲」形成循環
元素：
- 中央標籤「熾焰咆哮虎」
- 格子「上場」
- 格子「擊掌奇襲」
- 格子「拋下狠話換下」
- 格子「再上場重發威嚇」
- 箭頭：上場 → 擊掌奇襲 → 拋下狠話換下 → 再上場重發威嚇 → 擊掌奇襲
動畫：沿著循環依序亮起
