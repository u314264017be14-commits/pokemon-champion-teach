# card-04：Lv.50 能力值計算（Stat Calculation）
來源：wiki/concepts/stat-calculation.md
主題類別：控速機制

## 核心定義（1～2 句）
VGC 統一以 50 等計算，所以每隻寶可夢的實際能力值都能用種族值、個體值、努力值和性格精確算出來，這是速度線和傷害計算的基礎。

## 關鍵事實與數值
- 能力值由種族值、個體值（0–31）、努力值（單項最多 252、總和最多 510）、性格（×0.9 / ×1.0 / ×1.1）決定（§定義）（補充，非 raw 來源）
- Lv.50 公式：其他能力 = ⌊(⌊(2×種族值 + 個體值 + ⌊努力值/4⌋) / 2⌋ + 5) × 性格修正⌋（§數值與計算）（補充，非 raw 來源）
- 個體值 31 時，努力值有效配置是 4、12、20……252（4 + 8n），配成 8 的倍數會浪費 4 點（§數值與計算）
- 振翼髮速度：最速 205、不加速性格 187（§數值與計算）
- 熾焰咆哮虎：HP 202、最高速度 123、最低速度 58（§數值與計算）
- 速度速查：種族值 60 → 58 / 80 / 112 / 123；種族值 135 → 126 / 155 / 187 / 205（最低 / 無投資 / 極速 / 最速）（§數值與計算）（補充，非 raw 來源）

## 新手常見誤區
- 努力值配 8 的倍數：Lv.50 應配 4 + 8n，例如 252
- 用種族值直接比速度：要比實際能力值
- 忘記性格修正要捨去小數：例如 205.7 → 205

## 可用於簡報的例子
- 速度差 1 點就可能決定整場比賽（§為什麼重要）
- 配速度線：目標速度加 1 就是自己需要的速度，剩下的點數配耐久（§實戰應用）
- 戲法空間隊伍反過來把速度壓到最低（個體值 0 加減速性格）（§實戰應用）
