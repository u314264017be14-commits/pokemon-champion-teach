# 雙打核心節奏：速度線、控速與優先度

## 1. 出手順序基本原則
- 在沒有特殊場地效果時，場上寶可夢依照「速度能力值」由高到低依序行動。
- 雙打戰局中，搶到先手權往往能先一步擊倒對手核心，因此「控速」是雙打最重要的戰術軸心。

## 2. 兩大核心控速手段
- **順風（Tailwind）**：在己方場地刮起順風，提升我方全體寶可夢的速度，適合中高速進攻隊伍搶奪先手壓制力。
- **戲法空間（Trick Room）**：扭曲時空，倒轉出手順序，讓「速度較慢」的寶可夢比「速度較快」的寶可夢先出手。

## 3. 招式優先度（Priority）的絕對規則
- 招式自身的「優先度」永遠優先於「速度值」以及「戲法空間」的倒轉效果。
- 即使場上已開啟戲法空間，優先度 +1 的先制招式（如「神速」、「影子偷襲」）依然會比優先度 0 的一般招式先出手，不受空間影響。
