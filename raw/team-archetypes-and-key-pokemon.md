# 新手必學：經典雙打隊伍體系與核心單卡

## 1. 經典雨天體系（Rain Team）
- **核心組合**：大嘴鷗 ＋ 海豚俠。
- **運作邏輯**：利用大嘴鷗的「降雨」特性進場搶奪雨天環境（水系招式 1.5 倍），搭配海豚俠的變身機制與高威力水系招式，在開局對敵方造成巨大輸出壓力。

## 2. 重空間體系（Hard Trick Room）
- **核心組合**：愛管侍 ＋ 敗露球菇。
- **運作邏輯**：愛管侍進場開啟「精神場地」阻擋對手的先制招式（如擊掌奇襲），掩護隊友安全開出戲法空間；空間開啟後，敗露球菇利用極低的速度搶先施放「蘑菇孢子」控場。

## 3. 雙打賽場核心單卡範例
- **振翼髮（Flutter Mane）**：
  - 屬性：幽靈 / 妖精；特性：古代活性。
  - 種族值（總和 570）：HP 55 / 攻擊 55 / 防禦 55 / 特攻 135 / 特防 135 / 速度 135。
  - 定位與招式：極高特攻與速度的輸出手，常見招式為魔法閃耀、暗影球、冰凍之風（控速）與守住。
- **熾焰咆哮虎（Incineroar）**：
  - 屬性：火 / 惡；特性：威嚇（進場降低對手雙邊物攻）。
  - 種族值（總和 530）：HP 95 / 攻擊 115 / 防禦 90 / 特攻 80 / 特防 90 / 速度 60。
  - 定位與招式：頂級輪轉輔助，藉由「威嚇 ＋ 擊掌奇襲 ＋ 拋下狠話」反覆削弱對手並掩護隊友上場。
