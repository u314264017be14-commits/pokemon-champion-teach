# Lv.50 能力值計算（Stat Calculation）

> VGC 統一以 50 等計算，所以每隻寶可夢的實際能力值都能用種族值、個體值、努力值和性格精確算出來。這是速度線和傷害計算的基礎。

## 定義

能力值由四個變數決定（補充，非 raw 來源）：

| 變數 | 說明 | 範圍 |
|---|---|---|
| 種族值（Base Stats） | 物種固定的基礎數值 | 依物種而定 |
| 個體值（IV, Individual Values） | 每隻個體天生的數值 | 0–31（對戰用通常練滿 31） |
| 努力值（EV, Effort Values） | 透過培育分配的點數 | 單項最多 252，總和最多 510 |
| 性格（Nature） | 一項能力值 ×1.1、另一項 ×0.9，或兩項都不變 | ×0.9 / ×1.0 / ×1.1 |

VGC 統一 Lv.50 的規定見 [[concepts/vgc-format]]。

## 為什麼重要

- 雙打的勝負常取決於「誰先出手」，所以速度能力值差 1 點就可能決定整場比賽。
- 知道對手的最高、最低速度後，才能決定自己的速度要配多少努力值（俗稱「速度線」）。
- 傷害計算也以實際能力值為基礎，而不是種族值。

## 數值與計算

### 公式（第三世代以後）（補充，非 raw 來源）

```
HP      = ⌊(2×種族值 + 個體值 + ⌊努力值/4⌋) × 等級/100⌋ + 等級 + 10
其他能力 = ⌊(⌊(2×種族值 + 個體值 + ⌊努力值/4⌋) × 等級/100⌋ + 5) × 性格修正⌋
```

### 代入 Lv.50 後的簡化

```
HP      = ⌊(2×種族值 + 個體值 + ⌊努力值/4⌋) / 2⌋ + 60
其他能力 = ⌊(⌊(2×種族值 + 個體值 + ⌊努力值/4⌋) / 2⌋ + 5) × 性格修正⌋
```

### 努力值的「4 + 8n」原則（個體值 31 時）

- 個體值 31 時，`2×種族值 + 31` 是奇數，所以**最初的 4 點努力值**就能讓能力值 +1。
- 之後**每 8 點努力值 +1**。
- 所以有效的努力值配置是 4、12、20、28 …… 252。配成 8 的倍數會浪費 4 點。

### 計算範例

**振翼髮（Flutter Mane）速度**（種族值 135）
- 個體值 31、努力值 252、性格加速：⌊(270 + 31 + 63) / 2⌋ = 182 → 182 + 5 = 187 → 187 × 1.1 = 205.7 → **205**
- 不加速的性格：**187**

**熾焰咆哮虎（Incineroar）**（HP 95 / 速度 60）
- HP（個體值 31、努力值 252）：⌊(190 + 31 + 63) / 2⌋ + 60 = 142 + 60 = **202**
- 最高速度（努力值 252、性格加速）：⌊(120 + 31 + 63) / 2⌋ + 5 = 112 → × 1.1 = **123**
- 最低速度（個體值 0、努力值 0、性格減速，適合戲法空間（Trick Room））：⌊120 / 2⌋ + 5 = 65 → × 0.9 = 58.5 → **58**

### 速度能力值速查（Lv.50）

| 種族值 | 最低（個體值 0 / 減速） | 無投資（個體值 31 / 不加減） | 極速（努力值 252 / 不加減） | 最速（努力值 252 / 加速） |
|---|---|---|---|---|
| 60 | 58 | 80 | 112 | 123 |
| 135 | 126 | 155 | 187 | 205 |

（補充，非 raw 來源）

## 實戰應用

- **配速度線**：先算出要超越的目標的速度值，加 1 就是自己需要的速度，再反推最少要投資多少努力值，剩下的點數拿去配耐久。
- **戲法空間（Trick Room）隊伍**：反過來把速度壓到最低（個體值 0 加減速性格），確保在戲法空間下先手。
- **讀對手配置**：從對手的出手順序反推對方有沒有投資速度、是不是加速性格。

## 常見誤區

- **努力值配 8 的倍數**：Lv.50 時應該配 4 + 8n，例如 252 而不是 256（也不可能超過 252）。
- **用種族值直接比速度**：種族值相近的寶可夢，可能因為努力值與性格不同而順序顛倒，要比實際能力值。
- **忘記性格修正要捨去小數**：乘完性格修正後要無條件捨去，例如 205.7 → 205。
